# UK Tax Self-Assessment Calculator Web App for PAYE employees
[Click here](https://taxcalc-app-web-app-6lp36syjj38k8bhqts3wif.streamlit.app/) to see the app in action

I created this Streamlit app to help me complete my self-assessment tax return without needing to refer to excel spreadsheets!
It assumes the user receives a salary with income tax and National Insurance deducted via PAYE.

It is designed to take account of pension contributions, salary sacrifice, bank interest, property income and charitable giving.
It also calculates child benefit payments.
